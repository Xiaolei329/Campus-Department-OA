## 📌 项目简介

本项目是一个基于 **Spring Boot** 和 **Vue 3** 构建的前后端分离高校院系级办公自动化（OA）管理系统。

本项目重点针对**高校、教研机构及大学院系**的实际办公场景，旨在提升内部教务日常管理的效率与协同办公能力。系统涵盖了教职员工管理、多节点工作流审批、日常教研协同任务分配、会议室场馆预约以及教案文档共享等多项高频应用。

系统架构引入了 **Redis** 高速缓存优化鉴权与业务效率并设计了以 **Nginx** 为核心的反向代理动静分离部署模式。项目代码结构严谨、注释详尽，非常适合作为**计算机专业毕业设计**、**高级课程设计**或个人进现实战演练的项目参考。

## 🚀 技术栈详情

### 核心后端技术
- **核心框架**：`Spring Boot 2.7.x` 
- **持久层支持**：`MyBatis-Plus 3.5.3` (提供高效灵活的 CRUD 支持与分页查询)
- **安全认证**：`Spring Security` + `JWT`
- **高速缓存中间件**：`Redis` (全面介入系统认证架构，负责 Token 状态管理、强制下线以及高频数据的缓存读取)
- **数据库**：`MySQL 8.0+`
- **数据导出组件**：`EasyExcel` (基于实体类的高性能 Excel 文件导入与导出处理)
- **依赖管理构建**：`Maven`

### 前端技术栈
- **开发应用框架**：`Vue 3` (采用新一代 Composition API Setup 语法)
- **前端路由管理**：`Vue-Router 4.x` (支持动态菜单及路由层面的细粒度权限拦截)
- **状态管理**：`Pinia 2.x`
- **UI 组件库**：`Element Plus` (提供高质量、现代化的桌面端管理界面交互)
- **图表数据面板**：`ECharts 5.x` (承载 Dashboard 大屏的高级数据可视化图表)
- **网络异步请求**：`Axios`
- **极速构建工具**：`Vite 4.x` (提供开发态秒级冷启及稳定的生产打包)

### 运维与部署环境
- **网关及静态代理**：`Nginx` (用于前端页面高效托管以及对后端服务的反向代理)

## ✨ 核心功能模块

1. **🔒 安全与动态权限控制 (Auth & Security)**
   - 采用 `JWT + Redis` 相结合的强化鉴权体系。
   - 实现细粒度角色鉴权，涵盖超级管理员、院系/教研室主任、普通教职工等多级角色隔离。保障接口层级的操作安全。
2. **📊 可视化教务控制台 (Dashboard)**
   - 集成 ECharts 提供直观明了的教务及审批数据看版。
   - 一眼概览：本周待办任务统计、教务人员出勤分布概览、院系公告触达率等多维度关键业务指标。
3. **👥 院系组织架构与用户管理 (System)**
   - 树状展示的部门/专业架构支持。
   - 支持教职员工档案管理、动态修改隶属院系及分配内置系统角色，支持针对特殊状态账号的离职封禁操作。
4. **📁 教案与公共文档资源库 (Doc / File)**
   - 实现院系内部文件的云端存储化。
   - 支持教案课件、规章制度及学术报告文件的极速分发下载与权限控制。
5. **📢 院级全员通告墙 (Notice)**
   - 支持后端通过集成富文本编辑器发布图文并茂的放假通知或活动公示。
   - 保证重大教务信息的精准全栈触达。
6. **📅 场馆与会议室可视资源预约 (Meeting)**
   - 专业化场地预定模块，涵盖：**学术报告厅**、**教师会议室**、**学校党委会议室**、**学科教研会议室**以及**主任会议室**。
   - 系统级自动完成物理资源的防碰撞排他校验，彻底杜绝排期重叠问题。
7. **🤝 任务委派与协同办理 (Task / Collab)**
   - 院系/教研组领导一键下派阶段性学术或行政任务。
   - 详尽记录全节点追踪（待签收 -> 处理中 -> 完结审核 -> 闭环归档）。
8. **📠 工作流与请假调班审批 (Workflow)**
   - 标准化的无纸化审批流体验（包含事假、病假、调课调休等多种模式）。
   - 线上闭环流程：由下属教职工发起申请 -> 院系主任或对应主管审批（同意并流转/提出修改驳回）-> 自动消息反馈。

## ⚙️ 快速运行与部署指南

### 1. 基础环境库准备
- **数据库**：安装并启动 `MySQL 8.x`，创建对应的本地实例库：`CREATE DATABASE oasystem;`，随后通过可视化工具或命令行将 `/sql/oasystem.sql` 脚本完整导入，完成表构建与初始化数据写入。
- **缓存组件**：安装并让 `Redis` 保持后台运行状态（系统默认识别 `127.0.0.1:6379`）。

### 2. 拉起后端工程
1. **必要依赖环境**：JDK 1.8 或 JDK 11+ 环境、Maven 3.6+ 构建工具。
2. **初始化配置参数**：定位并打开 `backend/src/main/resources/application.yml` 文件。
    - 认真修改 `spring.datasource` 下的数据库连接账号与密码信息为您本地配置。
    - 若本机 Redis 非免密或非默认端口，请修改 `spring.redis` 下的相关参数。
3. **依赖更新与启动**：在使用 IDE（如 IntelliJ IDEA）将 Maven 包结构 Reload 完成后，在 `com.example.office.OfficeApplication` 类处右击 `Run` 启动。后端正常将挂载并监听本地的 `8080` 端口。

### 3. 拉起前端工程
1. **必要依赖环境**：安装不低于 `Node.js v16` 的引擎。
2. **模块依赖安装**：在命令行工具进入 `frontend` 所处根目录后执行包下载安装命令：
   ```bash
   npm install
   ```
3. **执行本地构建**：
   ```bash
   npm run dev
   ```
4. **前端查验访问**：执行完成，命令控制台通常会给出一串类似 `http://localhost:5173/` (Vite) 或 `http://localhost:80/` (具体视本地配置及 Nginx 环境而定) 的调试地址。在浏览器键入即可看到系统的精美登录页。

> 💡 **生产级别部署提示**：若要在公网 Linux 环境上线答辩，极度建议您使用 `npm run build` 命令打包出纯静态 `dist` 产物，使用 **Nginx** 进行部署并利用其将前台 API 请求反向代理给 8080 端口，从而真正实现物理级别的前后端分离。
